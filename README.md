# Zaitoon Family Restaurant — Website & Smart Dining System

The official website and smart dining system for **Zaitoon Family Restaurant**, Wah Cantt.

## Features
- **Website:** 3D hero, full menu with photos and prices, about, gallery, reviews, rewards, FAQ and contact
- **Dine-in & Reserve:** book a table online, or order from your table by QR code or NFC
- **Live order tracking** for dine-in and takeaway
- **Kitchen display:** live tickets with timers, 80 mm KOT printing, waiter assignment
- **Waiter app:** table map, guest calls, kitchen messages, take orders, settle bills
- **Admin panel:** orders, menu, tables and QR codes, waiters, reservations, guest CRM, offers, feedback
- **Notifications** for guests, kitchen and waiters
